本文档描述页面的视觉规范与交互契约，界面截图见 `docs/screenshots/`。
- 依赖全部本地化：`vendor/echarts.min.js`（ECharts 5）、`vendor/fonts/NotoSansSC-400.woff2`、`-700.woff2`（不依赖外网 CDN）。
- 数据契约（JSON 形状、指标口径）见根目录 `DATA_CONTRACT.md`。

## 2. 视觉规范（沿用参考站，必须一致）

- 页面背景 `#0b0e14`，面板 `#12161f`（圆角 14px、1px 边框 `#1f2633`），卡片同面板色。
- 主蓝 `#4fc3f7`、橙 `#ffb74d`、紫 `#b388ff`、红 `#ef5350`、绿按钮 `#2e7d32`（hover `#388e3c`）。
- 字体：`NotoSansSC` 本地 @font-face，fallback `"Microsoft YaHei", sans-serif`；数字用 `font-variant-numeric: tabular-nums`。
- 标题 16px 700；卡片大数字 30px 700；说明文字 12px `#8b95a7`。
- ECharts 主题：透明背景，`axisLine/splitLine` 用 `#1f2633`，轴文字 `#8b95a7`，line 宽 1.6~2。
- 顶栏右侧「刷新数据」是绿色实心按钮，带 ⟳ 图标；刷新中禁用 + 文案「刷新中…」。

## 3. 卡片（3 个，顺序：沪深300、中证500、科创50 与契约 `indices` 一致）

每卡片渲染（使用当前**指标** = 成交PCR 或 持仓PCR、当前窗口 N、当前带宽 k）：

- 第一行：色点 + 名称 + 代码（`510300.SH`）；右侧状态 pill：
  - `z >= k` → 红底 pill「突破上轨(+{k}σ)」；`z <= -k` → 绿/青底「跌破下轨(-{k}σ)」；否则 `中性` 灰底。
- 大数字：当前 PCR 值（保留 2 位）；旁边小字 `z={z:+.2f} · 稳健z={rz:+.2f}`，z 为正红/负绿。
- 四行键值：`中枢`、`上轨+{k}σ`、`下轨-{k}σ`、`滚动分位`（0~100%，保留 1 位）。
- 底行小字：`成交PCR {v:.2f} · 持仓PCR {o:.2f}`（两者始终显示，当前指标高亮）。
- 点击卡片切换「焦点指数」（当前选中卡片边框高亮为主题色）。

## 4. 图表

### 4.1 主图 `#chartMain`

- 标题动态：`{名称} · {指标名} 通道（MA{N} ± {k}σ）`；副标题：样本区间 + 交易日数量。
- series：
  1. 焦点指数 PCR：`type:'line'`, `showSymbol:false`, 宽 2, 色 `#4fc3f7`。
  2. 另两个指数 PCR：宽 1.2、透明度 0.35、各自的颜色，作背景对比（可被开关隐藏）。
  3. 中枢（焦点）：色 `#ffb74d`，宽 1.8。
  4. 上轨/下轨（焦点）：色 `#ef5350`，dashed，宽 1.2，`areaStyle` 可选（上下轨之间淡红填充 opacity 0.04）。
  5. 突破点（焦点）：`type:'scatter'`, 红点 `#ff5252`，size 6，仅 `|z|>=k` 的点。
- 时间轴：`type:'time'`，日期 `[date, value]` 数据对。
- dataZoom：`inside`（滚轮/拖拽缩放）+ `slider`（底部条，高 22，`#141a26`）；两图共享同一缩放区间。
- tooltip：`axisPointer:'cross'`，展示日期、PCR、中枢、上/下轨、z、分位；数值保留 3 位小数。
- legend：底部或右上，可点击切换「对比指数」「通道」显示（可选，但至少能切换对比线）。

### 4.2 Z 图 `#chartZ`（高度约 200px）

- 焦点指数 `Z 值`（实线，色 `#4fc3f7`）+ `稳健 Z`（虚线，色 `#ffb74d`）。
- 水平参考线：`y = +k`、`y = -k`（红色 dashed opacity 0.5）与 `y=0`（灰虚线）。
- 与主图共享 dataZoom（任一图缩放，另一图跟随；用 `echarts.connect(group)` 或手动 dispatchAction）。

## 5. 状态与交互

- 初始状态：`焦点指数=kc50`？→ 默认取 `indices[0]`（沪深300），`指标=成交PCR`，`win=250`，`k=2.5`，展示全部历史。
- 期权 PCR 窗口列表 = `[5, 10, 20, 60, 120, 250, 500]`（v3 起新增 5/10/20/60 短周期）；期货窗口列表仍为 `[120, 250, 500]`，两套列表互不影响（hash 里期货 `win=5` 会被忽略）。
- 统计窗口**含当日值**，因此 `|z|` 的理论上界是 `sqrt(N-1)`：`N=5 → |z| ≤ 2`，所以在默认 `k=2.5` 下 5 日窗口永远不会出现突破点/「突破上轨」pill（`k=1.5/2` 仍可出现）。这是 §2 z 定义的正确结果，不是 bug。
- 稳健 Z 在极短窗口下可能因 MAD 极小产生大尖峰（如 N=5 历史极值可达 ±50 量级），因此 Z 图 y 轴对 `|Z|` 与 `|稳健Z|` 做以 0 为中心的稳健截断（p99.5×1.15，且不低于 `k+1.5`），曲线 `clip` 显示、tooltip 仍给出原始精确值，数据不做任何过滤。
- 切换窗口/带宽/指标/焦点：**纯前端重算**，不请求后端（滚动统计在 JS 里算）。
- 刷新按钮：`POST /api/refresh` → 成功后 `GET /api/data` 重新渲染，toast：
  `新增 {new_days} 个交易日 · 最新 {latest_trade_date} · 用时 {elapsed}s`；
  失败 toast 红色错误信息；409 忙碌文案按接口返回的 `error` 显示。
- 首次加载：请求 `/api/data`；若 500/缺失，页面显示引导文案（启动 `python serve.py` 或点刷新）。
- 页面右上「更新时间」显示 `数据更新至 {latest_trade_date} · 生成 {generated_at}`。
- 全部交互状态同步到 URL hash（见 DATA_CONTRACT.md §7），并支持页面加载时读取 hash 恢复。
- `#bootState`、`window.__PCR` 按契约 §7 实现（自动化验证依赖它）。
- 响应式：宽度 < 1280 时卡片换行、工具栏换行；图表随容器 resize。

## 6. 可复用要点（参考项目 app.js 里值得照搬的）

- 数字格式化（千分位、保留位数）、日期轴 `axisLabel` 的 `formatter`（按跨度显示 年-月）。
- 暗色 ECharts option 的公共部分（`backgroundColor:'transparent'`、`splitLine`、`tooltip` 样式）。
- 刷新按钮的 loading / toast 实现。
- 卡片 DOM 模板与 CSS 网格布局。

## 7.5 期限结构图 `#chartTerm`（新增，独立一张）

- 面板标题：`贴水 vs 到期月 · {trade_date}`，副标题：
  `横轴=到期时间，纵轴=年化贴水率%（正=贴水）；每个点是一个在交易合约，按到期日由近到远排列`。
- 数据来自 `data.term_structure.indices[]`（4 个品种），每个 `contracts` 已按 `expiry` 升序。
- x 轴 `type:'category'`，label 用两行：`{code}` + `{MM-DD}`（如 `IF2611` / `11-20`），或 `{code}\n剩余{dte}天`。
  所有品种的到期日可能不同：以 4 个品种到期日的并集排序（同年同月按日），空格处不连线（数据点按自身日期落在对应类目）。
- 4 条线（每个品种一条），颜色 `indices[].color`，宽 2、`showSymbol:true`、symbolSize 7；
  近月 → 远月的连线就是该品种的期限结构。
- y 轴名 `年化贴水率 %（正=贴水）`；画 `y=0` 灰虚线（升水/贴水分界）+ `y=±2σ/±5%` 可省，但 0 线必须有。
- tooltip：`{品种} {code} · {expiry} 到期（剩余 {dte} 天）`、`期货 {fut} · 基差 {basis:+.1f} 点 · 基差率 {basis_rate:+.3f}% · 年化贴水 {ann:+.2f}%`。
- legend 可点击隐藏单个品种；图高约 300px，宽 100%。

## 7.6 刷新与状态

- 刷新按钮沿用 v1：`POST /api/refresh`，回包新增 `futures: {ok, elapsed, days, latest_trade_date, new_days, error?}`。
  toast 合并展示两个子系统，例如：
  `期权：新增 0 日（共 1652） · 期货：新增 1 日（共 1523） · 用时 14.2s`；
  `futures.ok=false` 时红色 toast 追加「期货：{futures.error}」，但期权数据仍刷新。
- 刷新成功后：重新 `GET /api/data`；若期货数据已在内存则同时 `GET /api/futures`（on-demand 也可）。
- 「更新时间」行：`数据更新至 {latest_trade_date} · 生成 {generated_at}`（取当前 tab 的数据源）。
- 首次进入期货 tab 若 `/api/futures` 返回 503：面板显示引导文案「还没有期货数据，点击右上角刷新」+ 按钮。

# v3 修订：期货升贴水改为「恒定到期」跟踪（2026-10-21 追加，对应契约 §11/§12）

## 8.1 为什么要改（写进页面说明文案的依据）

- 旧口径「近月年化贴水」受两条干扰：① 剩余天数很小（1~7 天）时 `365/dte` 把正常基差放大成 ±50% 的尖峰；
  ② 每月换月主力合约切换会让序列跳变（2018-10 以来 95 次换月，跳变均值 6.6pp、中位数 5.3pp、最大 23.5pp）。
- 新口径「恒定到期 30 天」：每天用相邻两合约基差插值到 30 天再年化，序列不再随换月跳变
  （原型：50 日窗口内最大单日变化 cm30=4.6pp vs 近月 5.1pp，长窗口差距更大；2015-2026 全样本年化波幅也明显收窄）。
- 页面用一句 `#futNote` 文案说明：「默认跟踪 30 天恒定到期年化贴水（消除换月跳变与近月年化放大）」+ 近月实况仍在卡片底行。

## 8.2 指标切换改三档（`#fmSeg`）

- 顺序：`恒定到期 30D`（默认）→ `近月年化` → `近月基差率`，data 值分别为 `cm` / `ann` / `basis_rate`。
- 选中 `cm` 时序列取 `indices[].cm_ann`（null 点不画、遇 null 断开）；选 `ann` → `ann`；`basis_rate` → `basis_rate`。
- 卡片大数字：`cm`/`ann` 显示 2 位小数 + `%`；`basis_rate` 显示 3 位小数 + `%`。
- MA{N}/σ/±kσ/Z/稳健 Z/滚动分位全部基于当前选中序列（与 PCR 侧同一套函数，缺值跳过，不把 null 当 0）。

## 8.3 卡片（每张，顺序不改）

- 第一行不变：色点 + 名称 + `IF2611` + 状态 pill（pill 依据当前选中序列的 z 与 k）。
- 大数字 = 选中指标最新值；小字 `z={z:+.2f} · 稳健z={rz:+.2f}`（cm 口径缺失时显示 `—`）。
- 四行键值不变：`中枢` / `上轨+{k}σ` / `下轨-{k}σ` / `滚动分位`（都按选中序列算）。
- 底行改为：`近月 {code} · 基差 {basis:+.1f} 点 · 剩余 {dte} 天 · {expiry} 到期 · 30D 年化 {cm:+.2f}%`
  （`近月` 明细取 `latest`，`30D 年化` 取 `latest_cm.ann`；两者恒显示，与当前指标无关）。

## 8.4 主图 `#chartFut` / Z 图 `#chartFutZ`

- 标题动态：`{名称} · {指标名} 通道（MA{N} ± {k}σ）`，指标名分别 `恒定到期 30D 年化` / `近月年化贴水` / `近月基差率`。
- 副标题追加口径提示：`cm 口径=插值到 30 天年化（正=贴水）`；`ann 口径=近月主力年化（受剩余天数放大）`；`basis_rate 口径=（期货/现货-1）`。
- 轴名/tooltip：按选中指标给单位与符号方向（沿用 v2 的「正=贴水/负=贴水」提示）；tooltip 三行在选中 cm 时给
  `恒定到期基差 / 恒定到期基差率 / cm 年化`，并附 `近月 {code} 基差` 一行对照。
- Z 图：直接复用 PCR 侧 `zDisplayMax()` 稳健截断（cap 8，clip:true，tooltip 原始值），不再自动量程。
- dataZoom 双图联动、窗口 120/250/500、带宽三档都不变。

## 8.5 期限结构图 `#chartTerm`（不变）
